# Trivare

Professionele one-page website voor Trivare, een digitale partner voor Nederlandse mkb-bedrijven. De site positioneert webdesign, UX, SEO, CRO, onderhoud en branding in een hoogwaardige zwart-wit-gouden stijl.

## Lokaal starten

```bash
pnpm install
pnpm dev
```

## Productiecontrole

```bash
pnpm build
```

## WordPress

De code bevat een voorbereide WordPress REST-koppeling. Zie `WORDPRESS.md` voor de twee mogelijke migratiepaden: WordPress als headless CMS of omzetting naar een custom WordPress-theme.
